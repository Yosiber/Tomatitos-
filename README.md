# 🍅 TomatoVision — Clasificación y Segmentación de Tomates con IA  

Este proyecto incluye un sistema completo para **clasificación** y **segmentación** de tomates utilizando **TensorFlow**, **Flask**, **YOLO**, y un **frontend en React**.

El backend ofrece dos funcionalidades principales:

- **Clasificación** (3 modelos disponibles)
- **Segmentación** (YOLO con máscaras, contornos y etiquetas)

---

## 🚀 Tecnologías usadas

### **Backend**
- Python 3.10+
- Flask
- TensorFlow
- YOLO (ultralytics)
- OpenCV
- NumPy
- Pillow

### **Frontend**
- React + JavaScript
- Fetch API para enviar imágenes
- Estilos personalizados (neumorphism o según configuración)

---

## ⚙️ Instalación del Backend

1. Clona el repositorio:

```bash
git clone https://github.com/usuario/tomato-vision.git
cd backend
``` 
2. Crea y activa un entorno virtual:

```bash
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
```

3. Instala dependencias:
```bash
pip install -r requirements.txt
```

4. Ejecuta el servidor:

python app.py
